# 赛前 30 分钟检查单（演示不翻车守则）

## T-30 环境与数据

- [ ] 关闭投影机网络依赖预期：全程断网可演（模型入口自动降级「演示模式」徽标）
- [ ] 打开产品（浏览器单文件 或 Windows 壳），确认标题为 2.6.0
- [ ] 「起点」页点一次「导入示例教材」——识网有节点、知债有红边（约 3–25 秒）
- [ ] 若现场想走 3 秒路径：知债页空态「载入演示诊断（示例红边）」，并在口播中说明是演示数据
- [ ] 「账户」页：确认免打扰（演示模式）**关闭**（危机提醒演示需要弹卡）；音量合适（危机有提示音）
- [ ] 关掉首次引导弹窗（「？」帮助中心 → 关闭），或已点过一次不再自动弹

## T-10 演示彩排一遍关键拍

- [ ] 识网 → 知债「重新诊断」→ 点开最红边（公式解读 3 秒能讲清）
- [ ] 「生成 14 天计划」→ 绿色徽标「计划合约 K1–K5 校验通过」一定出现
- [ ] 「今日」作答一题：拖信心滑条 → 提交 → 掌握度变化
- [ ] 智能体输「我不想活了」→ 转介话术 + 常驻提醒卡 → 点「知道了」收起（**确认后导航才不被遮挡**）
- [ ] 「账户」撤销授权 → 「教师」页即时不可见
- [ ] What-if 拖滑杆：impact 实时复算、≥0.08 判红

## T-0 纪律

- [ ] 每句数字都有页面出处：0.08 阈值 / K1–K5 / 连续 2 次∧累计 3 次 / 1–5 信心
- [ ] 不说「AI 会学习/自动优化」之类未实现的话；演示模式徽标在就承认是本地规则
- [ ] 危机演示严肃对待，一笔带过转具体交互，不渲染情绪
- [ ] 翻车预案：见 demo-script-3min.md 故障预案表（账户页一键重建 30 秒；预录视频兜底）
