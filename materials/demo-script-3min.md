# 演示脚本 · 3 分钟（v2.6.0 · 对齐当前产品交互）

> 原则：每句话评委都能在产品里当场核对；所有数字来自本地公式，不依赖网络与模型可用性。
> 交互路径均标注实际按钮/页面；⭐ 为「评委记得住」的高光拍。

## 0:00–0:15 开场（口播 + 已打开的首页）

「学生不是不努力，而是跨课的先修知识债拖住了后继课程。知债：星穹学途把债算清楚，再给出可执行、可校验的 14 天修复计划。」

画面停在「起点」页，已导入示例教材（见检查单：开演示前点一次「导入示例教材」）。

## 0:15–0:50 算债：从教材到红边 ⭐

1. 点「识网」：章节/术语节点 + 先修边，红色边即开放知识债
2. 点「知债」→「重新诊断」：红边清单按影响分降序
3. 点开最红的一条：展示「现状—拖累对象—建议动作」的债务解读
4. 口播真实公式（与页面 What-if/画像「公式详情」一致）：
   `影响分 = base × σ(先修掌握差) × σ(后续掌握差) × 边权 × 跨章系数 × 频次因子，≥ 0.08 判为开放红边`
5. 口播：「这套数字只由本地公式算出，大模型无权改写——下面每一步都一样。」

## 0:50–1:35 修债：14 天计划与合约引擎 ⭐⭐

1. 点「生成 14 天计划」：计划官编排，产出带「为什么排这天」的任务卡
2. 指给评委看绿色徽标：**「计划合约 K1–K5 校验通过」**
   - K1 每天 ≤40 分钟；K2 先修有序；K3 说明必含先修点；K4 同点同日不重复；K5 开放债边被覆盖或显式延期
3. 点「今日」→ 选任务 →「开始练习」：拖**信心滑条（1–5）**后提交，掌握度即时更新
4. 口播销账规则：「连续 2 次达标且累计 ≥3 次、加权 ≥0.65 才算结清——销账只能由状态机写入。」

## 1:35–2:05 安全与伦理（评委最关心的部分）⭐

1. 「智能体」页输入「我不想活了」→ 立即转介话术 + **常驻提醒卡**（点击「知道了」才收起，免打扰下也不静音）
2. 「账户」页点「撤销授权」→ 「教师」页该生数据即时不可见（fail-closed，k-匿名下限 3 人）
3. 口播：「默认不可见、学生自主、非处分依据；危机词命中是全链路最高优先级。」

## 2:05–2:40 计划跟不上怎么办（新能力，一句话一个）

- 「请假暂停 3 天」：暂停期不提醒、不计连续未完成，到期自动恢复原计划
- 「本周减半」：剩余任务时长按一半折算，随时「立即恢复」
- 连续 3 天未完成 → 减负建议（7 天冷却）；连续进展每满 7 天 → 鼓励
- 「账户」页「免打扰（演示模式）」：投影时不弹提醒，危机提醒仍可见

## 2:40–3:00 收尾：四端与工程底座（口播 + 材料页）

「同一套核心，跑在四个端：浏览器单文件（33 MB 全内联、断网可用）、Windows（托盘常驻）、Android、鸿蒙（ArkUI 原生，直板/折叠双形态适配）。质量上：244 项单元测试、60 项跨语言金样、34 步一键验收与持续集成，演示的每一步都有自动化测试守着。」

## 故障预案（更新版）

| 故障 | 动作 |
|---|---|
| 网络/模型不可用 | 全程本地链路不受影响；智能体标「演示模式」徽标继续答 |
| 演示数据被我改乱 | 「账户」页一键清除演示诊断 / 重置本机数据，30 秒重建 |
| 识网等太久 | 知债页空态点「载入演示诊断（示例红边）」，3 秒出红边（标注演示数据） |
| Windows 壳异常 | 连续 3 次启动失败自动进恢复模式（清零/数据目录/清缓存三选一） |
| 设备整体翻车 | 预录 3 分钟视频兜底（与脚本逐拍对应） |
